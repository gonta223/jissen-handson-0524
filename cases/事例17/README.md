# 事例17（🟠）：商談相手の課題仮説と提案要旨を朝までに自動生成、表紙画像まで添える

**課題**：商談直前のリサーチが浅く、相手の最新ニュースを見落として話が薄くなる

**やること**：商談直前リサーチで相手のニュースを見落とし浅い話に → 公開情報と過去議事録を踏まえ、課題仮説3つ・提案要旨・想定問答・表紙画像を朝までに自動生成。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
今日14時の「ある中堅製造業の顧客」との商談準備を一式やってください。公開情報と最近のニュースをリサーチ、過去議事録 meetings/ あれば全件踏まえ、相手の課題仮説3つ・提案要旨1枚・想定問答5セット・表紙スライド画像をgpt-image-2で1枚生成。出典URLと取得日時を必ず残してください。
```

**ひとこと**：meetings/{client}/ を必ず参照させ、出典URLと取得日時を残す。公開用と社内用でファイルを分ける。
