# 事例17（🟠）：プレスリリースを報道文体で執筆、配信ポータル下書き入稿まで自動化

**課題**：プレスリリースのたびに構成・執筆・入稿で半日が消える

**やること**：発表のたびに構成→執筆→入稿で半日溶ける → 報道文体で執筆し、PlaywrightでPR TIMESの下書き入稿まで自動化。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
次の内容でプレスリリースを書いて、PR TIMESの下書き入稿までやってください(公開はしない)。発表内容: <新サービス名・対象・開始日・特徴3つ・代表コメント・問い合わせ先>。構成: タイトル30字/サブ/リード200字/本文(背景→内容→今後)/会社概要/問い合わせ先。文体は報道向け客観・誇張なし、数値は円表記固定。Playwrightで下書き画面まで自動投入してください。
```

**ひとこと**：冒頭でNG表現リスト（「業界初」「最高」「+」「k/M略記」）を明示。公開は人間がOKを出すまで絶対やらせない。
