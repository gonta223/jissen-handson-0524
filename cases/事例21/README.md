# 事例21（🟠）：メンバーとの1on1準備を、議事録・Slack・成長記録から自動生成

**課題**：1on1のたびに「前回何を話したっけ」と議事録やSlackを掘り返して時間が溶ける

**やること**：1on1のたびに「前回何話したっけ」を探すのに時間が溶ける。過去の議事録・Slackの直近ログ・カレンダー・メンバーごとの成長記録（member_context）を1つに束ねて、当日そのまま使える1on1準備メモを自動生成。準備にかけていた30分前後が、数分に圧縮されます。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
明日の田中さんとの1on1の準備メモを作って。
・直近3回のtldv議事録から「前回の宿題と、その後どうなったか」
・Slackの直近2週間のやりとりから、いま気にしていそうなトピック
・成長記録 member_context/tanaka.md の目標と前回までの課題
これらを統合して「今日聞くべきこと3つ／労うべき成果／注意して見る点」を1枚に。
```

**ひとこと**：成長記録（member_context）を一緒に渡すのが肝。単発の議事録だけだと「点」の話になるが、継続ファイルを足すと「線」で見られる。準備が速くなると1on1の頻度を上げられる。
