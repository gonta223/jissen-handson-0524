# 事例24（🟠）：見込み客の機械収集から、コールドメール下書きまで揃える

**課題**：見込み客リストを手で集め、1社ずつ最初の一通を書くのに時間がかかりすぎる

**やること**：エリア×業種×規模でターゲット企業を機械収集し最初の一通まで用意したい → React+PythonフルスタックをTDDで構築し、Maps API取得→課題仮説→コールドメール下書きまで生成。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
Uravation Leads という見込み客リスト収集アプリをTDDで構築してください。バックエンドPython+フロントReact、入力はエリア/業種/規模、Maps APIで企業取得→公開情報と口コミから1社1課題仮説→コールドメール文案を生成→leads.csvと送信ドラフトを出力。APIキーは.envから、コミットしないこと。送信機能は実装しないこと。
```

**ひとこと**：APIキーは1コミット目から.env+.gitignoreで隔離。メールは送信せず下書きで止めて一通ずつ手動確認。
