# 事例47（🔵）：英語のオープンソースツールを、並列分担で日本語化＋自社向けに改修

**課題**：便利な英語OSSを見つけても、UIや内部プロンプトが英語のままで社内にそのまま使えない

**やること**：英語のスライド生成OSSをサブエージェント20体で領域分担し、UI・内部プロンプトを日本語化＋自社向けに改修。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
このOSS（https://github.com/<owner>/<repo>）をフォークして自社版に魔改造してください。やること: (1) UI文言を全部日本語化 (2) 内部プロンプト（英語）を日本語＋自社文体ルールに書き換え (3) 自社で使う機能を2つ追加。ファイル/機能ごとに並列で分担。ライセンスを先にチェックし、フォーク・改変が許可されているか確認。改造後ローカルで動作確認してから報告。
```

**ひとこと**：まずライセンス確認（フォーク・改変可か）。並列改造はファイル領域を分けて衝突回避、改変箇所が分かるように残す。
