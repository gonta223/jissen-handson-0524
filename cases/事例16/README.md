# 事例16（🟠）：分散したデータベースを横断で束ね、経営ダッシュボードを毎月自動生成

**課題**：Notionの案件・請求・タスクDBがバラバラで、会社の全体像が一目で見えない

**やること**：NotionのプロジェクトDB・請求DB・タスクDBがバラバラで全体像が見えない → API直叩きで全レコードを取得し、Tier分類と進行案件一覧を毎月1枚のダッシュボードに自動生成（Notionの外に出力）。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
Notionの「プロジェクト管理」「請求書管理」「タスク管理」DBをAPI直叩きで読み、クライアントを売上規模と継続性でTier(A/B/C)分類、進行案件22件を一覧化、当月の請求予定と入金状況のサマリーを dashboard_202605.md に。書き込みは一切しないでください。
```

**ひとこと**：「読み取りメイン・書き込みはしない」と明示して事故防止。クライアント18社・案件22件を毎月1枚に集約。
