# 事例3（🔵）：雑談混じりの生メモを、1枚構造化報告書に整形

**課題**：雑談混じりの生メモを上司向け報告書に整える作業が毎回じわじわ手間

**やること**：雑談混じりの生メモから、サマリー・決定事項・ネクストアクション（担当・期限の表）・リスクの4ブロックに取捨選択して、上司向け1枚報告書（400〜600字）に整形。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
memo.txt を読んで部長向け社内報告書にMarkdown整形。構成: サマリー1行/決定事項/ネクストアクション(担当・期限の表)/リスク。雑談メモは除外、フォーマル、400〜600字。
```

**ひとこと**：「誰向けの報告書か」を最初に言わないと口調が中立になる。雑談メモは「含めない」と明示すれば自動除外、tldvの生文字起こしをそのまま渡してOK。
