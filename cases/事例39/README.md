# 事例39（🟠）：自由記述アンケートを意味クラスタリングで圧縮し、改善優先度を出す

**課題**：アンケートの自由記述が数百〜数千件あって読み切れず、結局どこを直すべきか分からない

**やること**：アンケートの自由記述が数百〜数千件で読み切れず改善点がボヤける。意味でクラスタリングして上位テーマ＋代表コメントを抽出し、ネガを深刻度で優先度付けします。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
reviews.csv(回答500件、満足度スコア+自由記述)を分析してレポートにしてください。
1. スコア分布(平均/分布/NPS的分類)
2. 自由記述を意味でクラスタリング(embedding+K-means)し上位5テーマ+代表コメント3つ
3. ポジティブ/ネガティブに分けて、ネガを深刻度で優先度付け
4. 全体所感を1,000字
個人名・所属はマスクしてください。出力: review_report.md
```

**ひとこと**：「単語一致じゃなく意味で分ける」と明示。ネガは件数でなく深刻度で優先順位を付け、個人名・所属は出力前に必ずマスクします。
