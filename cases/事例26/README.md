# 事例26（🟠）：取材当日の情勢調査・台本・スライド画像を、並列で30分以内に揃える

**課題**：取材や登壇の当日朝、最新情勢の調査から台本・スライドまで手が回らず準備が間に合わない

**やること**：取材・登壇当日に最新情勢リサーチから台本・スライド画像まで一気に揃えたい → 17体並列リサーチ＋台本生成＋画像生成を30分以内に。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
今日の取材（テーマ:「中小企業の生成AI活用の現在地」）の準備を一式やって。
- まず最新の業界情勢を17体のサブエージェントで並列リサーチ
  （直近3ヶ月の事例・数値・トレンド、出典必須）
- それを踏まえて、30分尺・スライド30枚分の台本を作成
  各スライド: タイトル / 話す内容（200字）/ 図解の指示
- 想定される鋭い質問を5つと回答案
- 主要スライド5枚分の画像をgpt-image-2で生成
出力: daihon.md + slides/ + qa.md
```

**ひとこと**：「直近◯ヶ月」と期間明示で出典必須。台本は字数指定、画像生成はレート制限回避で主要数枚に絞る。
