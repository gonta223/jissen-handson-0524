# 事例26（🔵）：作ったサイトをClaude Designに渡し、LP案を20種出させて最良案をCCに戻す

**課題**：自分のデザインセンスに自信がなく、LPの見た目づくりで手が止まってしまう

**やること**：自分のデザインセンスで手が止まる → Claude Codeで作ったサイトをClaude Designに渡し、レイアウト・トーン違いのLP案を十数〜20種出させて、気に入った案をまたClaude Codeに戻して本実装。「作る→デザイン提案→実装」を一往復させる。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
いまローカルにあるこのLP（index.html）をClaude Design用に整理して。
そのうえで「ファーストビューだけ、レイアウト・配色・訴求トーンを変えた案を
12〜20種、1画面に並べて比較できる形」で提案して。各案にねらいを一言。
良い案を選んだら、その方向で index.html を本実装まで書き換えて。
```

**ひとこと**：出力がイマイチなのは「Claudeの能力が低い」んじゃなくて、こちらの **デザインの引き出しが少ない** だけ、ということが多い。案を大量に出させて"選ぶ"側に回ると、自分のセンス以上のものが出ます。最後の実装はCCに戻すと一気通貫。
