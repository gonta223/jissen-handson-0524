# 事例38（🔵）：複数視点が要る市場調査を、3部門チーム編成で並列深掘り

**課題**：一人で市場を調べると視点が偏り、市場規模も技術も検索需要も見落としが出てしまう

**やること**：市場規模・技術動向・検索需要と複数視点が要る市場調査 → 3部門チームを並列起動し、独立深掘り後に統合提言まで。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
「中小企業向け補助金活用支援」市場を3部門チームで並列調査して。
- 市場チーム: 市場規模・主要プレイヤー・成長率・参入障壁
- 技術チーム: 申請業務のどこをAIで自動化できるか・既存ツール
- SEOチーム: 「補助金 申請 代行」等の検索需要・競合サイトの強さ
- 各チームを並列起動して独立に調査（出典必須）
- 厚労省・経産省の公式パンフPDFも参照
- 最後に3チームの成果を統合し、参入すべきか・どこから攻めるかを提言
出力: market_report.md（各部門の調査 + 統合提言）
```

**ひとこと**：部門の役割を明確に分けて重複防止。各部門に出典必須、「最後に統合・提言」で羅列に終わらせない。
