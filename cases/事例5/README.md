# 事例5（🔵）：講座スライドを、テンプレートで統一デザイン量産

**課題**：講座のたびにスライドを1枚ずつ手作りして、数百枚分の時間が溶ける

**やること**：講座台本Markdownから、要点3つ以内・章扉とまとめ自動挿入のルールでMarpスライドを一括ビルドし、数百枚を統一デザインで量産。1枚ずつ作る手作業を消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
daihon.md からMarp形式の講座スライド作成。theme: uravation-v2、1枚3要点以内、章扉とまとめ自動挿入、図解はコメントで指示だけ。PDFまでビルド、エラーは自分で直して。
```

**ひとこと**：1枚に詰め込むと本番で読めないので「要点3つ以内」を縛る。テーマCSSを使い回すと全スライドのデザインが揃い、Marpのビルドエラーは貼って直させると速い。
