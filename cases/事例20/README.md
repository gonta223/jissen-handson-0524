# 事例20（🔵）：新規案件のフォルダ構造と雛形を、ひとつのコマンドで一気に展開

**課題**：新規案件のたびにフォルダ作成・README・雛形コピーを手作業で繰り返している

**やること**：新規案件ごとに6サブフォルダ作成・README・雛形コピーを手作業 → 1コマンドでフォルダ構造と雛形を一気に展開。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
新規クライアント案件のフォルダ構造を作ってください。場所: projects/ 配下に「2026_◯◯株式会社」。サブフォルダ6つ「1.提案」「2.案件シート」「3.議事録」「4.契約」「5.納品物」「6.請求」。各フォルダに用途を書いたREADME.md。「2.案件シート」にはtemplates/案件シート.mdをコピー。協業パートナーの有無は最初に聞いて、ありなら名前を「2026_◯◯株式会社_[協:〇〇]」に。作成後にツリー表示してください。
```

**ひとこと**：協業パートナーの有無を作る前に必ず確認（命名規則が変わる）、生成後にツリー表示で目視確認。

---
- バッジ：🔵（🔵=Claude単体で実装可／🟠=外部API・設定が必要）
- このフォルダは Claude Code 実践編「活用事例50選」の 事例20 を、**自分の環境でバーっと試す用**の雛形です。
- 入力ファイルが要る事例は `input/` にサンプルを置いています（無い事例はプロンプトだけでOK）。
- データはすべて架空。実行は自己責任で、送信・課金・削除など外向き/不可逆操作の前は必ず人間が確認してください。
