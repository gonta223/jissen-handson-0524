# 事例48（🟠）：途中で止まるAI実装を、自律ループで完成まで自走させる

**課題**：AIに実装を任せても8割あたりで止まり、完成まで何度も自分で再開を促すのが面倒

**やること**：「80%で止まる」問題を、Stopフックの自律ループで完了条件（テスト全パス等）を満たすまで自走させる。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
次のタスクを自律ループで完成まで回してください。途中で止まらず確認も待たないでOK。ゴール: <ツール>を「pytestが全パス・READMEに使い方/例/注意点が揃っている」状態にする。各ループ: 現状確認 → 不足を1つ直す → テスト実行 → まだなら次のループ。上限100ループ。完了したら止まる。不可逆操作（本番デプロイ・削除）の時だけ確認して。
```

**ひとこと**：完了条件は「テスト全パス」など機械判定できる形に。上限回数を必ず設け、不可逆操作の前だけ止める。
