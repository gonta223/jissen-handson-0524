# 事例36（🟠）：「忙しいのに成果が出ない」を、週次メタ認知レポートで改善策に変える

**課題**：忙しく動いている割に成果が出ず、何に時間を使っているか自分で客観視できない

**やること**：「忙しいのに成果が出ない」を客観視する仕組みがない。週次でログ・カレンダー・タスクを突き合わせ、具体策付きの改善提案を3つ出します。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
今週の私の働き方をログから分析してメタ認知レポートを作ってください。
データ源: Claude Codeセッションログ、Googleカレンダー、完了タスクログ
分析:
1. 時間配分(どの種類の作業に何時間使ったか)
2. 繰り返している作業(自動化・スキル化の余地)
3. 成果(完了した重要タスク)と未完了の積み残し
4. 集中できた時間帯・分断された時間帯
来週の改善提案を3つ、具体的なアクション(時間帯・トリガー付き)で。
出力: metacognition_YYYYWW.md
```

**ひとこと**：ログだけだと考えていた時間が見えないので必ずカレンダーと併用。改善提案は「火曜午前は会議を入れない」のように具体策で縛ります。
