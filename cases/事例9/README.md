# 事例9（🔵）：肥大化したClaude Code環境を、棚卸しダッシュボードで可視化

**課題**：スキルやMCPを入れすぎて、いま何が入っているか・何が使われていないか把握できない

**やること**：スキル・MCP・エージェント・cronが300本超で何が入っているか把握できていない。全部走査して用途・最終更新日・頻度の一覧にし、棚卸し候補をフラグします。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
私のClaude Code環境を可視化するダッシュボードを作ってください。
対象: ~/.claude/skills/(各SKILL.md)、.mcp.json、launchd plist、crontab
まとめる内容:
1. 導入スキル一覧(名前/用途/最終更新日/直近30日の利用頻度)
2. MCP接続一覧(サービス/用途)
3. 定期実行ジョブ一覧(何が・いつ動くか)
4. 半年以上更新なし・重複・利用頻度ゼロのものを棚卸し候補としてフラグ
削除はしないで提案までで止めてください。
```

**ひとこと**：「使われていない」を最終更新日だけで判定すると誤検知するのでセッションログと突き合わせ。削除はせず提案までで止め、月次で回します。
