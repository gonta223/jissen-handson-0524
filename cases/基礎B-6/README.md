# B-6（🔵）：月次の数字を集計してレポート化

**課題**：月次レポートを数字だけ入れ替えて作り直す定型作業に毎月追われる

**やること**：売上・経費CSVをローカルPythonで集計し、前月比・内訳・推移グラフ＋変化点コメント付きの月次レポートを生成。数字を入れ替えるだけの定型作業を消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
今月の月次レポートを作ってください。

- データ: uriage.csv(日付/商品/金額)、keihi.csv(日付/勘定科目/金額)
- 集計はローカルPython(pandas)で行い、グラフはmatplotlib(Hiragino Sans)で出力:
  1. 今月の売上合計・経費合計・差引(前月比%も)
  2. 商品別・勘定科目別の内訳
  3. 直近6ヶ月の売上推移グラフ
- 各数字に「先月から何が増減したか」を一言コメント
- 金額は円表記(2,000万円 / ¥980,000 のように)。「+」やM/k略記は使わない
- 出力: monthly_report_202605.md + 推移グラフ画像
- 元データの合計と集計結果が一致するか検算して、ズレたら報告して
```

**ひとこと**：「元データの単純合計と一致するか検算して、ズレたら報告」を必ず指定（行の取りこぼし検知）。日本語フォント崩れは「Hiragino Sansを使って」で解決。
