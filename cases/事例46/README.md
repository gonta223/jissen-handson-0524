# 事例46（🟠）：毎分スクショ→AIが画像分析→1日の終わりに日報と図解を自動メール

**課題**：一日の終わりに、結局今日何に時間を使ったのか思い出せずモヤッと終わる

**やること**：「今日、何に時間を使ったか」が分からない → Macの画面を毎分スクショしてAIに画像分析させ、1日の終わりに「何に何分使ったか」の日報と図解を自動生成して自分宛にメール。見えなかった自分の1日が可視化されます。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
cronで毎分このMacのスクリーンショットを撮って screenshots/ に保存する仕組みを作って。
1日の終わり（19時）に、その日のスクショをGemini APIで分析して
「何の作業に何分使ったか」を集計 → 日報（Markdown）＋時間配分の図解にまとめ、
自分のGmail宛に送って。画像はローカル保持、外に送るのは集計結果だけにして。
```

**ひとこと**：記録は「自動で溜まって、勝手に届く」状態にするのが続くコツ。スクショ画像はローカルに留め、外に出すのは集計だけにすると安心。1週間回すと、自分の時間の溶け方に気づけます。
