# 事例19（🟠）：大量の会話履歴を、意味で検索できる自分専用DBに資産化

**課題**：SlackやLINEの会話が何十万件も溜まっているのに、あの話どこだっけと探せず埋もれる

**やること**：Slack・Discord・LINE・Claude Codeのログに会話が50万件以上溜まっているのに探せず資産にならない。これを意味で検索できる自分専用DBに資産化します。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
過去の全会話履歴を意味で検索できるDBにしてください。
データ源: Slackエクスポート、Discordログ、Claude CodeセッションログのJSONL。
1. 各履歴をパースして「日時/相手/本文」に正規化
2. 発言・スレッド単位でチャンク分割しOpenAI embeddingでベクトル化
3. VPS上のSQLite FTS5に格納(認証付きディレクトリ)
4. `convo-search "<自然文>"` で類似会話を返すCLIを作る
まず直近1ヶ月で動作確認してから全件投入してください。
```

**ひとこと**：いきなり全件投入せず直近1ヶ月で動作確認してから拡張。チャンクは発言・スレッド単位で区切ると検索精度が出ます。
