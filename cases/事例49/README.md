# 事例49（🟠）：思いついたWebアプリを並列実装してサーバー公開まで一気に到達

**課題**：思いついたWebアプリを、実装からサーバー公開まで一人でやり切るのに時間がかかりすぎる

**やること**：思いついたWebアプリ（GitHub探索のTinder風UI）を、フロント／バック／API連携の3領域に並列分担して実装し、本番VPS公開まで一気に到達。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
次のWebアプリを作ってVPSに公開してください。大きいので並列で分担して進めて。アプリ: GitHubの面白いリポをTinder風UI（スワイプ）で発掘。機能: トレンドリポ取得／スワイプUI／「いいね」したリポ一覧保存。構成: フロント（React/Next.js）／バックエンド（API）／GitHub API連携 の3領域を並列実装。インターフェースは先に確定。統合→ローカル確認→VPSデプロイ。APIキーは.envから、コミットしない。デプロイ前と公開前は確認して。
```

**ひとこと**：インターフェース（APIの形）を先に確定してから並列分担すると統合がスムーズ。公開前にキー漏れ・認証を確認。
