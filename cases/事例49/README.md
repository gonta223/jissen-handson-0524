# 事例49（🟠）：生活データ（睡眠・活動）をMCPで読み、毎朝の自分レポートをSlackに自動配信

**課題**：Oura等で睡眠や活動を測っても数字を眺めるだけで、予定との因果まで読み解けない

**やること**：Oura Ringの睡眠・HRV・活動量をMCPで読み、カレンダーの予定と突き合わせて「会議を詰めた翌日にHRVが落ちる」といった因果まで分析。毎朝cronで自動実行し、その日の体調と過ごし方の提案をSlackに自動投稿する。「Claude Codeは仕事だけ」の枠を外す1本。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
Oura（MCP）から直近2週間の睡眠スコア・HRV・活動量を取得して。
カレンダーの予定と突き合わせて、
・睡眠とパフォーマンスの相関、HRVが落ちた日の前日に何があったか
・今日の体調の見立てと、無理しない過ごし方を3つ
をまとめて。これを毎朝7時にcronで回して Slack の #self に投稿する段取りも書いて。
```

**ひとこと**：データを「見る」だけでなく「毎朝勝手に届く」状態にするのが続くコツ。仕事のログと同じ仕組み（MCPで読む→cronで自走→Slackに流す）が、健康管理にもそのまま効く。
