# 事例4（🔵）：1万字記事を、観点別検証つきで執筆

**課題**：1万字級の記事を書くと、事実や文体のチェックが後回しになって品質がブレる

**やること**：テーマと結論から先にアウトラインを固め、本文執筆と並行して(事実・論理・文体・冗長・重複)の観点別検証Subagentを並列で走らせ、1万字記事を品質担保つきで出す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
「中小企業のClaude Code導入5ステップ」で10,000字。先にアウトライン固定。本文と並行して(a)事実(b)論理(c)文体(d)冗長(e)重複の5観点で検証Subagentを並列。指摘を統合して1回リライト。
```

**ひとこと**：検証は観点ごとに分けて並列で走らせると深さが出る。アウトラインを先に固めないと文字数だけ膨らむ。
