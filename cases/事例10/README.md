# 事例10（🟠）：重い処理と機密データを、ローカルLLMに逃がしてコストと安全を両取り

**課題**：何でもClaudeに投げると課金がかさみ、機密の音声をクラウドに上げるのも怖い

**やること**：「全部Claudeに投げると高いし、機密音声をクラウドに上げたくない」を解決。重い推論・最終判断はClaude、定型処理・翻訳・同じ処理の繰り返し・NDA案件の音声文字起こしは手元のローカルLLMに振り分けて、コストと情報漏洩リスクの両方を下げる。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
この一連の処理を「ローカルでやるべきか / Claudeでやるべきか」で振り分けて実行して。
・大量CSVの前処理／定型抽出／同じ整形の繰り返し → ローカル（Ollama・Qwen）に回す
・複雑な設計判断・最終レビュー → Claude（あなた）が担当
・このNDA案件の会議音声（audio/）→ ローカル文字起こし（Parakeet-MLX）。クラウドには送らない
最後に「どれをローカルに逃がして、API課金をどれだけ減らせたか」を一覧で教えて。
```

**ひとこと**：全部ローカルにするのではなく「重い・機密・繰り返し」だけ逃がすのがコツ。手元のMacで動くモデルでも前処理と翻訳なら十分。機密音声は"そもそもクラウドに上げない"のが最強のセキュリティ。
