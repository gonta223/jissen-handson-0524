# 事例30（🟠）：海外ニュース調査と記事化を、並列で全自動化

**課題**：海外メディアやSNSを毎朝ひとつずつ見て回り、既出チェックまで手作業で消耗する

**やること**：海外メディア・掲示板・SNSを並列で横断収集し、既出と照合・二重ファクトチェックした上で、自分の文体で毎朝のまとめ記事を全自動ドラフト。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
sources.txt の情報源を全部並列で取って、過去7日の既出と照合、Codexで裏取りした上で voice.md の文体で5本ドラフト。出典URL必須。
```

**ひとこと**：「裏が取れないものは除外」を明示し、過去7日の archive/ を必ず参照させないと、ソース不明ネタや同じ話の使い回しが出る。
