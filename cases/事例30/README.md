# 事例30（🔵）：競合と自社の立ち位置を、URL投入だけで差別化ポジション付き比較表に

**課題**：提案前や参入前に競合と自社の立ち位置を整理したいが、各社サイトを見比べるのに時間が溶ける

**やること**：提案前・参入前に相手と自分の立ち位置を素早く整理したい → 3社のURL投入で比較表化し、自社の差別化ポジションを導出。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
この3社のサイトを読んで比較表にまとめて。
https://a-corp.example.com/service
https://b-corp.example.com/pricing
https://c-corp.example.com/about

- 比較軸: 料金 / メインの特徴 / ターゲット顧客 / 訴求コピー / 強み / 弱み
- 4列以上の比較表（Markdown）で
- 最後に「自社が取るべき差別化ポジション」を3行で
- 各社、サービス紹介・料金・事例の各ページを別々に読むと精度が上がります
出力: competitor_compare_YYYYMMDD.md
```

**ひとこと**：SPAサイトは本文が取れないことがあるので別手段に切替。料金・事例ページも個別に渡すと精度が上がる。
