# 事例30（🟠）：図解の試行錯誤を、複数スタイル並列一括生成で短縮

**課題**：図解のデザイン案を1案ずつ作っては却下する試行錯誤に時間を取られる

**やること**：図解の中身を固め、10種類のデザインスタイル×バリエーション=30枚を並列一括生成し、コンタクトシートで一気に方向性を比較。1案ずつ却下する時間を消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
「AI導入3ステップ(現状把握→小さく試す→全社展開)」の図解を10スタイル各3枚=30枚並列生成。16:9、日本語ラベル、装飾過多にしない。最後にコンタクトシート1枚。
```

**ひとこと**：画像生成プロンプトでドル記号「$」はシェル変数と衝突するので金額は「0.08ドル」と日本語表記。30枚一気はレート制限に当たるのでスタイルごとにバッチを分ける。
