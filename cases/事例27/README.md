# 事例27（🟠）：週報の情報収集を1コマンド化、親機能が子機能を連鎖実行

**課題**：週報のためにGitHub・カレンダー・Slackを毎週手で巡回し、情報集めだけで疲れる

**やること**：週報の情報収集（GitHub／カレンダー／Slack）→整形→投稿を1コマンド化。親Skillが子Skill4本を連鎖実行して集約。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
/weekly-report を実行して今週の週報を作ってください。親Skill weekly-report が子Skillを順に呼ぶ: (1) gather-github → 今週のコミット/PR (2) gather-calendar → 今週の会議 (3) gather-slack → 主要チャンネルの動き (4) format-weekly → 「成果/課題/来週の予定」に整形。子で取得失敗したものは「(取得失敗・要手動)」と入れて全体は止めない。出力: weekly-reports/2026-WW.md。
```

**ひとこと**：依存は必ず親→子の片方向（循環参照を防ぐ）。子の失敗は「(取得失敗・要手動)」で続行、子は軽量モデル指定でコスト圧縮。
