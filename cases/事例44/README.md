# 事例44（🔵）：CLAUDE.mdとメモリを「経営判断OS」にして、毎朝ひとりで壁打ちする

**課題**：経営判断を一人で抱え、賛成も反論もしてくれる壁打ち相手がそばにいない

**やること**：意思決定を一人で抱えて壁打ち相手がいない。自分の価値観・過去の判断・会社の状況をCLAUDE.mdとメモリに溜め、用途別のスラッシュコマンドで「壁打ち・反論・事前検死・役割のズレ検知」を呼び出せる"判断OS"にする。外部接続なし、Claude単体で完結。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
.claude/commands/ に、経営判断用のスラッシュコマンドを作って。
・/sparring … 私の案に賛成せず、別の角度から3つ反論してくる壁打ち相手
・/premortem … 「この施策は半年後に失敗した。なぜ失敗したか」を5つ挙げる事前検死
・/role-check … 今週の動きが、私が本来やるべき役割からどれだけズレているか診断
判断材料は CLAUDE.md の経営方針と memory/ の過去ログを必ず参照。
おべっかは禁止、根拠を添えて答えて。
```

**ひとこと**：AIに同意させても意味がない。「賛成するな・反論しろ」を仕込むのが全て。判断のログを memory に溜めるほど、自分の思考のクセまで指摘してくれる相棒になる。
