# B-5（🔵）：領収書・レシート→会計ソフト起票用に仕分け

**課題**：毎月の領収書仕分けで「これ何費だっけ」と勘定科目に悩む時間が積もる

**やること**：`receipts/` の領収書をローカルPythonのOCRで抽出し、勘定科目を確度付きで推定。毎月の仕分けと「これ何費だっけ」の時間を消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
receipts/ フォルダの領収書・レシート画像を読んで、会計起票用に仕分けてください。

- まずローカルPython(pytesseract/pdfplumber)で「日付 / 支払先 / 金額 / 但し書き」を抽出するスクリプトを書いて実行
- 抽出結果(raw_receipts.csv)を受け取り、内容から勘定科目を推定:
  旅費交通費 / 会議費 / 消耗品費 / 通信費 / 接待交際費 / 新聞図書費 など
- 判断に迷うもの・読み取れない金額は [要確認] フラグを立て、断定しない
- 金額は円表記(¥1,980 のように)。「+」やM/k略記は使わない
- 出力: keihi.csv(日付 / 支払先 / 金額 / 勘定科目 / 但し書き / 確度 / ファイル名)
- 私用と業務の区別が付かないものも [要確認] に回して
```

**ひとこと**：感熱紙の劣化で誤読が起きるので金額は断定させず確度を出させ、怪しいものは `[要確認]` に回して人間が最終判断。
