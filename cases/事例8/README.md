# 事例8（🟠）：過去バズを、ワンクリックで完全復元投稿

**課題**：過去にウケた投稿を再利用したいのに、毎回手で打ち直すのが面倒で放置している

**やること**：再現したい過去投稿のURLから本文・画像・リンクを丸ごと取得し、スレッドも順番どおり完全復元してTypefullyに下書き投入。手打ち再現の手間を消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
このURLの過去投稿を完全再現してTypefullyに下書き投入。スレッドなら全ツイート復元。「先週」等は今日基準の更新候補を別途。公開はせずDraft URL返して。
```

**ひとこと**：X公式APIは無料枠が実質使えないので外部API経由が現実解。公開は人間が承認（2段階承認）、古い数値と時制だけは見直す。
