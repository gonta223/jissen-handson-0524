# 事例8（🟠）：感覚頼りのSNSバズを、過去投稿分析で再現チェックリストに言語化

**課題**：SNSがたまにバズっても、なぜ伸びたか言語化できず次に再現できない

**やること**：SNSバズが感覚頼りで再現性が言語化できていない。過去投稿を分析して「伸びる投稿の再現チェックリスト」に落とします。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
posts.csv(4,026件、本文/imp/likes/RT/時刻)を分析して、伸びる投稿のパターンを抽出してください。
- エンゲージメント率で上位5%と下位5%を抽出
- 上位の共通要素(冒頭の型/文字数/時刻/テーマ/図解有無)を分析
- フォロワー数で正規化した相対値も併記
- 「再現可能なチェックリスト」に言語化
出力: viral_pattern.md と 時刻別/文字数別の伸びグラフ。
```

**ひとこと**：偶発バズに引きずられないよう必ず母数（上位5%）で評価。フォロワー変動期は相対エンゲージメント率で正規化します。
