# B-4（🔵）：請求書の発行（顧客・金額・期日→PDF生成）

**課題**：月末の請求で金額の転記ミスや発行漏れ、採番ズレが起きやすい

**やること**：宛先・金額・期日を流し込み、過去の `invoices/` を見て請求番号を採番してPDF発行。月末の転記ミス・発行漏れ・採番ズレを消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
請求書テンプレ(seikyu_template.html)に流し込んで、今月の請求書PDFを作ってください。

- 宛先: みなと商事 御中
- 件名: 生成AI研修(2026年5月分)
- 請求金額: 研修費 ¥600,000 + 設計費 ¥300,000(税抜) → 消費税10%を加算して税込合計を計算
- 支払期日: 2026年6月末日
- 請求番号: 連番(過去の請求記録 invoices/ を見て次の番号を採番)
- 振込先・自社情報はテンプレの固定値を使用
- 生成前に「宛先 / 税込金額 / 期日」を表示して、私がOKしてからPDF化
- 出力: invoices/2026/202605_みなと商事.pdf
```

**ひとこと**：金額ミスが致命的なので、生成前に「宛先・税込金額・期日」を画面表示→人間OK→PDF化の一手を必ず挟む。保存先は `/tmp` でなく正式フォルダへ。
