# 事例33（🔵）：繰り返し指示を過去ログから発掘し、自動スキル化

**課題**：毎回ほぼ同じ指示を打ち込んでいる自覚はあるのに、どれを部品化すべきか棚卸しできていない

**やること**：毎回同じ指示を出している自覚はあるがスキル化候補を棚卸しできていない。過去ログから3回以上の繰り返し作業を発掘し、SKILL.mdドラフトに整形します。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
私の過去ログから「繰り返している作業」を発掘して、スキルに昇格させてください。
対象: ~/.claude/projects/ 配下のセッションログ(過去30日)
1. 各セッションで「何をやったか」を要約
2. 似た作業を意味でクラスタリング
3. 3回以上繰り返している作業をスキル化候補として抽出
4. 各候補を SKILL.md(何をする/手順/プロンプトテンプレ)としてドラフト
毎回内容が違う作業はフラグだけ立てて、無理にスキル化しないでください。
```

**ひとこと**：毎回ちょっと違う作業は無理にスキル化せずフラグだけ。ドラフトは人間レビューを通す「スキルを作るスキル」です。
