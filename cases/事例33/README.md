# 事例33（🟠）：埋もれた商談ログから放置リードを並列で発掘し、成約まで繋げる

**課題**：商談が増えるとフォローが追いつかず、見込み客を放置したまま忘れてしまう

**やること**：商談が増えるとフォローが追いつかず放置リードが溜まる → 17体のサブエージェントで議事録・Slack・Gmailを並列捜査し、放置リードをスコア順に発掘して再アプローチ文の下書きまで用意。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
過去半年の商談記録(tldv議事録URL一覧+Slack商談チャンネル+Gmail)を17体のサブエージェントで分担分析して、「予算/時期/具体検討」発言ありで60日以上接触なしの放置リードを leads.md にスコア順で。再アプローチ文の下書きも添えて、送信はしないでください。
```

**ひとこと**：「興味あり」を社交辞令まで拾わないよう「予算/時期/具体検討」の3キーワードで縛るのがキモ。送信は必ず手動。
