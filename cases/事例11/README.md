# 事例11（🔵）：Macが急に重くなる原因を自己診断し、メモリを安全に解放

**課題**：Macが急に重くなって電池も減るのに、原因が素人には分からない

**やること**：Macが重く電池も減るが素人にはtopで原因が判断できない。メモリ・CPU上位を取得してClaudeが安全に終了できるものだけ提案、OKしたものをkillして前後比較（実例で約17GB解放）。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
Macの動作が重くて電池の減りも早いです。原因を診断して直してください。
1. vm_statとps aux --sort=-rssでメモリ・CPU上位プロセスを取得
2. 暴走している/異常にメモリを食っているプロセスを特定
3. システム必須プロセスは触らず、ユーザープロセスだけ終了候補として提示
4. 私がOKしたものだけ kill を実行
5. 実行前後の空きメモリを比較して報告
6. 不要な常駐ログイン項目の見直しも提案してください
```

**ひとこと**：システム必須プロセス（kernel_task, WindowServer等）は触らない。終了は人間OKの2段階承認で、常駐アプリ見直しまでセットにします。
