# 事例6（🟠）：プロモ動画を、コードでパラメータ化して量産

**課題**：プロモ動画をパターン違いで作るたび、1本ずつ手で編集し直していて終わらない

**やること**：Remotion動画コードの文言・配色・ロゴ・BGMをパラメータ化し、JSONを差し替えて並列レンダリングすることで、プロモ動画を40本超量産。1本ずつ編集する手間を消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
Remotionで15秒プロモ動画テンプレ作成。「課題3秒→解決2秒→特徴3つ各2秒→CTA3秒」。タイトル/サブコピー/特徴3つ/メインカラー/CTAをパラメータ化。研修・開発・コンサル向けの3バリエーション書き出し。
```

**ひとこと**：日本語フォントの埋め込み崩れが定番の罠。最初の1本で表示を目視確認してから量産する。
