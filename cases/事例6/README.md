# 事例6（🟠）：海外バズアカウントを解剖し、当たる構造を自分に逆輸入

**課題**：海外で何が当たっているのか構造がわからず、自分の発信に活かせていない

**やること**：海外で何が当たっているかを構造で学び自分の発信に逆輸入したい → 4アカウントの上位投稿をDL・解析し、転用できる型5つを抽出。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
海外で伸びている4アカウントを解剖して、バイラル分析レポートを作って。
- 対象: @acc1 @acc2 @acc3 @acc4（同ジャンル）
- pyktokで各アカウントの直近上位投稿を取得し、
  動画内容と字幕はGemini 3 Flashで解析
- 分析:
  1. 冒頭フックの型（数字/問い/逆説/告白 等）を分類
  2. エンゲージメント上位の共通要素
  3. 投稿フォーマット（画像/動画/スレッド）の比率
  4. テーマの傾向
- 4アカウント横断で「日本市場・自分の発信に転用できる型」を5つ
出力: viral_analysis.md + 投稿原文JSON（viral_raw/）
```

**ひとこと**：丸パクり・翻訳転載はNG、型の抽出に留める。動画解析はGemini 3 Flashに分業させてClaude側のコンテキストを節約。
