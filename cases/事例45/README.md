# 事例45（🟠）：AIをオンライン会議に参加させ、その場で発話までさせる

**課題**：AIを実際の会議に参加させて声で会話させたいが、何をどう繋げばいいか分からない

**やること**：AIをGoogle Meetに参加させ、音声を聞き取り・発話で応答する状態を、必要なツール調達ごと自走で構築させる。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
Claude CodeがGoogle Meetに参加して会話できる状態を作ってください。ゴール: Meetのリンクを渡したら参加して音声を聞き取り、応答を音声で返せる。進め方: 必要なツール・接続を自分で調べて接続。「できる状態になるまで自走」してOK、詰まったら別の方法を試す。各ステップのログは残す。不可逆な設定変更や課金の前だけ確認して。
```

**ひとこと**：「自走でできるまで」と指示しないと最初の壁で止まる。課金・不可逆操作の前だけ確認を入れる。
