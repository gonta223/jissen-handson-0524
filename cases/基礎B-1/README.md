# B-1（🔵）：メール返信の下書き（顧客文脈を反映）

**課題**：顧客ごとに毎回ゼロからメール返信を書いていて、地味に時間がかかる

**やること**：問い合わせ・お礼・日程調整の返信を、過去スレッドの文脈を踏まえて下書き生成。毎回ゼロから書く手間と、関係性が薄く見える事故を消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
次の受信メールへの返信を下書きしてください。送信はせず、Gmail下書き保存まで。

【受信メール】
（ここに本文を貼り付け）

- 相手: みなと商事の田中様。過去に1度研修見積もりをお送りした関係
- 今回の用件: 見積もりへの質問。日程の再調整も依頼されている
- トーン: 丁寧だが固すぎない、ですます調
- 必ず入れる要点: (1)質問への回答 (2)日程は来週前半で3案提示 (3)不明点はいつでも連絡を、の一文
- 200〜300字程度。署名は私の標準署名で
```

**ひとこと**：よく使う相手は CLAUDE.md に「相手・関係性・過去の論点」を3行で持たせると精度が跳ね上がる。送信は2段階承認で自動送信しない。
