# 事例41（🔵）：「並列の天井」の思い込みを壊し、サブエージェント100体同時起動を実証

**課題**：「サブエージェント並列は3〜5体が限界」という通説を鵜呑みにし、本当の上限を知らない

**やること**：「並列は3〜5体が限界」の思い込みを壊す。100個の独立タスクをサブエージェント100体に分割し、数波に分けて同時に回して1ファイルに集約。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
keywords.txt の100個を、1キーワード=1サブエージェント担当で並列実行してください。出力形式は「## キーワード / 定義 / 活用例 / 関連ツール」で統一。重ければ数波に分けてOK。全結果を results.md に集約。失敗があればどれが失敗したか報告して再実行。
```

**ひとこと**：出力フォーマットを完全統一して集約時にバラけさせない。読み取り専用ツールに限定して安全側に倒す。
