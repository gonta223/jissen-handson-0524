# B-8（🔵）：社内規定・マニュアルを使った問い合わせ一次回答（社内ナレッジ参照型）

**課題**：「あのルールどうだっけ」と毎回人に聞かれ、その都度調べて答えている

**やること**：社内規定DBやマニュアルを参照し、根拠（規定名・見出し）付きで問い合わせに一次回答。「ルールどうだっけ」を毎回人に聞かれる質問を減らす。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
社内の問い合わせに、社内規定・マニュアルを参照して一次回答してください。

- 参照ドキュメント: Notionの「社内規定」DB と manuals/ フォルダの各マニュアル
- 問い合わせ: 「出張の交通費って、どこまで経費で落ちる？申請の締切は？」
- 回答ルール:
  1. 必ず該当箇所を探して、根拠(どの規定の・どの見出しか)を明記する
  2. 根拠が見つからない・規定に記載がない場合は、推測で答えず「規定に記載が見当たりません。総務にご確認ください」と返す
  3. 回答は結論先出しで簡潔に。詳細は引用元へのリンク/見出しを案内
- 出力: 回答文 + 参照した規定の出典
- 読み取りのみ。Notionへの書き込みはしない
```

**ひとこと**：根拠が見つからない時は推測せず「記載なし」と返させるのが最重要（誤作文での事故防止）。出典必須、Notionは読み取りのみ。
