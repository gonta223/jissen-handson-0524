# 事例12（🟠）：正体不明な入出金を並列で素性照合し、勘定科目付与まで自動化

**課題**：確定申告期に正体不明の入出金が大量に出て、1件ずつ素性を照合するのが地獄

**やること**：確定申告期に正体不明の入出金が大量発生 → 36体のサブエージェントでGmail領収書・契約書・MoneyForward・請求記録を横断照合し、勘定科目付与まで自動化。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
fumei.csv の不明取引を1取引=1サブエージェントで分担し、Gmail領収書・契約書フォルダ・MoneyForward・請求記録Sheetを横断照合してください。勘定科目を付与し、確証が取れないものは [要確認] フラグ。出力は shiwake.csv(日付/金額/相手/勘定科目/根拠/確度) と 要確認一覧。
```

**ひとこと**：法人名義カード明細のみに限定し、確証が取れないものは必ず[要確認]に回させて税理士提出前に目視レビュー。
