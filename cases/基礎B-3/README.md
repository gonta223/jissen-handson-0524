# B-3（🔵）：見積書の作成（過去見積を雛形に金額・項目差し替え）

**課題**：見積書のたびにフォーマットを整え直し、単価感も毎回ブレてしまう

**やること**：過去の見積書を雛形に、今回の項目・数量・単価を差し替えて小計／税／合計を自動計算。毎回フォーマットを整え直す手間と単価感のブレを消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
過去の見積書(mitsumori_template.md)を雛形に、今回の見積書を作ってください。

- 宛先: みなと商事 御中
- 件名: 生成AI研修導入 お見積もり
- 項目と単価:
  - 研修プログラム設計 一式 ¥300,000
  - 集合研修 全3回 1回あたり ¥150,000
  - フォローアップ個別相談 5名分 1名あたり ¥30,000
- 小計・消費税(10%)・税込合計を自動計算
- 有効期限: 発行日から30日
- 金額はすべて円表記(¥300,000 のように)。「+」記号・M/k略記は使わない
- 出力: 見積書のMarkdown(後でPDF化する前提)。計算の内訳も併記
```

**ひとこと**：「小計→消費税10%→税込合計」の順で計算過程を出させて目視検算。雛形は前回の宛先・日付が残りがちなので清書前に全項目チェック。
