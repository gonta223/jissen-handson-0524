# 事例42（🟠）：寝ている間も会社を止めない、24時間自走のAI社員オフィス構築

**課題**：自分が寝ている間や会議中は作業が完全に止まり、調査や定型処理が翌日まで進まない

**やること**：寝てる間も会社が動く状態をつくる。朝刊・記事生成・SNS運用・経営アラートを役割別BOT＋cronで無人運転に。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
自分の代わりに定期作業をこなす自動化を、まず1人格から組んでください。役割「朝刊担当」: 毎朝7時にGmail未読要約+カレンダー予定+業界ニュース3本を1枚にまとめてSlack投稿。実装はスクリプト+cron登録+Slack Webhook通知。失敗時は止まらず続行、ログは必ず残す。動いたら次に「記事ネタ出し担当」を別人格で追加できる設計に。
```

**ひとこと**：いきなり50本組まず1人格1タスクから育てる。失敗時は「(取得失敗・要手動)」で止めず続行、ログ必須。
