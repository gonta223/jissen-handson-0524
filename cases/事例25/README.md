# 事例25（🔵）：海外記事を、自社への示唆まで日本語化するパイプライン

**課題**：英語の海外記事や論文を読む時間がなく、結局あとで読もうと放置して活かせない

**やること**：海外記事・論文を原文を読む時間なく取り込みたい → 要約だけでなく「自社への示唆」まで日本語化するパイプラインに。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
このURLの海外記事を、日本のAI研修事業者向けに日本語化して。
URL: https://...

- WebFetchで本文取得 → media-batchスキルで以下を生成:
  1. 3行要約（経営者目線）
  2. 重要キーワード5つ（英語→日本語、注釈付き）
  3. 本文翻訳（意訳OK、読みやすさ優先）
  4. 自社事業への示唆を2点（具体的なアクションまで）
- 人名・社名はカタカナ化せず原語＋「（米国のAIスタートアップ）」等の注釈で
- 取得できない場合（paywall等）は教えて。手動でテキストを渡します
```

**ひとこと**：paywallは手動でテキストを渡す。固有名詞は原語＋注釈、「示唆は具体的アクションまで」と指定し一般論を防ぐ。
