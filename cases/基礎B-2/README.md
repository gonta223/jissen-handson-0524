# B-2（🔵）：問い合わせの一次対応を定型化

**課題**：問い合わせ対応が人によってバラつき、返信漏れも起きてしまう

**やること**：過去の問い合わせログを意味でグルーピングし、頻出パターン上位8件の標準回答テンプレ集を生成。対応のばらつきと返信漏れを消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
過去の問い合わせ(toiawase.txt)から、よくある質問と回答テンプレ集を作ってください。

- 問い合わせを意味でグルーピングし、頻出する質問パターンを上位8つ抽出
- 各パターンに「想定質問 / 標準回答テンプレ(300字以内) / 補足が要る場合の追記例」を作成
- 回答テンプレ内の可変部分(日程・金額・担当者名)は <...> のプレースホルダで残す
- 金額が出る場合は円表記(例: ¥198,000)。「+」記号やM/k略記は使わない
- 出力: faq_template.md(質問パターン別の回答テンプレ集)
```

**ひとこと**：可変箇所は必ず `<...>` で残させないと過去案件の数字がそのまま残って事故る。月1で「最近増えた質問」を足して育てる。
