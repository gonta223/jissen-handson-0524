# 事例23（🟠）：note記事の整形・アイキャッチ・入稿を、ワンコマンドで一気通貫

**課題**：note入稿のたびに整形・タグ修正・アイキャッチ作成を手作業で繰り返している

**やること**：Markdown原稿をnote形式に整形し、非対応タグの検出・アイキャッチ生成・下書き入稿までワンコマンドで一気通貫。残りがちな手作業を消す。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
genko.md をnoteに下書き投稿。note形式に整形、非対応タグは事前検出、アイキャッチ3案→1つ生成→アップロード、下書き保存まで。edit_url返して、公開はしないで。
```

**ひとこと**：noteは特定HTMLタグを弾くので事前構文チェックで止めて修正。テーブルは3列に圧縮、公開は人間がOKを出すまでやらせない（2段階承認）。
