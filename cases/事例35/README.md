# 事例35（🔵）：AI業界キーパーソンの公開動画を、人物別並列で型抽出

**課題**：AI業界キーパーソンの動画を追いたいが、週1〜2本見るのが限界で追いつかない

**やること**：AI業界キーパーソンの公開動画（YouTube・登壇・ポッドキャスト）を週1〜2本見るのが限界 → 人物別に並列で字幕取得・要点抽出し、**自分の学習メモと、取材・対話のための質問リスト** にまとめる（他人の発信を「自分のコンテンツ」として出すのではなく、学びと取材準備に使う）。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
公開されているAI業界キーパーソンの動画リスト（urls.txt）を解剖して。
人物ごとに別エージェントを立てて並列で:
1. 字幕を取得（無い場合は文字起こし）
2. 主要トピック10点をタイムスタンプ付きで抽出
3. アウトプットは2つ（あくまで自分の学習・取材準備用）:
   - 自分用の学習要点メモ（1,500字）
   - 取材・対話時の質問リスト案（5問）
出典URL・該当タイムスタンプを必ず併記して。
※ 他人の発信を、自分のSNS投稿や配布コンテンツとして転用しないこと。
```

**ひとこと**：公開発信のみを対象に、発言はタイムスタンプ＋出典URL併記。**他人の発信を「自分のコンテンツ」として転用せず、学びと取材準備に留める** のが線引き。人物ごとに別エージェントにすると文脈が混ざらず精度が上がる。
