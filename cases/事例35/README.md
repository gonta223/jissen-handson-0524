# 事例35（🔵）：参加企業を並列Web検索で、優先順位つきリストに変える

**課題**：参加企業リストはあるが事業内容も規模も不明で、どこから営業するか決められない

**やること**：35社の参加者リストはあるが事業内容・規模・AI活用度が不明で営業先を決められない → 企業別に並列Web検索し、優先度スコア付きリストへ。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
companies.csv（社名/参加者名/URL）の35社を並列でWeb検索して、
事業内容・従業員規模・業界・AI活用の進度・想定課題を抽出。
「AI研修が刺さりそうか」を高/中/低でスコアリング（理由付き）。
スコア高い順にソートして targets.csv に出力。
公開情報がない場合は推測せず「情報不足」とフラグ立てて。
```

**ひとこと**：数社ずつバッチ分割でレート制限回避。情報がなければ「情報不足」とフラグ、スコアに理由を必ず付ける。
