# 事例43（🟠）：締切・未返信・契約更新の見落としを毎朝検知、Slack通知まで自動化

**課題**：締切・未返信・契約更新の見落としが積み重なり、気づけば経営事故になっている

**やること**：締切・未返信・契約更新の見落としが経営事故の8割 → launchdで毎朝8時にNotion・カレンダー・Gmail・議事録を並列チェックし、引っかかったらSlackに自動通知。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
HEARTBEAT 経営アラートBOTを作って毎朝8時に launchd で自動実行してください。監視対象はNotionタスクDB・Googleカレンダー・Gmail・議事録ネクストアクション。条件は締切3日以内/未返信5営業日/議事録期限超過/契約更新月接近。引っかかったら既存のSLACK_WEBHOOK_URLで#alertsに通知、既送はstate.jsonで重複排除してください。
```

**ひとこと**：条件は少数から始めて育てる。Webhook URLは既存を流用（grepで確認・コミット禁止）、既送はstate.jsonで重複排除。
