# 事例43（🟠）：溜まる一方の録画を、文字起こしとナレッジDB自動格納で検索資産化

**課題**：会議や講座の録画が溜まる一方で、あの発言どこで言ったかと後から探せず資産にならない

**やること**：会議・講座の録画が溜まる一方で後から探せず資産にならない。音声抽出→Whisper文字起こし→要約・アクション生成→Notion DBに自動格納し、launchdで毎晩自動実行します。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
recordings/meeting_YYYYMMDD.mp4 とチャットログ chat.txt を全自動アーカイブしてください。
1. ffmpegで音声抽出(10分単位で分割)
2. Whisper APIで文字起こし(話者ラベルできれば付与)
3. チャットログと時系列でマージ
4. 全文+3行要約+キーポイント+アクションアイテムを生成
5. NotionのDB「会議アーカイブ」に新規ページとして追加
精度が低い箇所は[聞き取り不明]とフラグ。書き込みは新規ページ追加のみ。
```

**ひとこと**：長尺は10分単位で分割して文字起こし。Notionは新規ページ追加のみで、既存ページの破壊的編集はさせません。
