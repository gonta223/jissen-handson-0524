# 事例1（🟠）：新書1冊の初稿を、1セッションで通しで書き切る

**課題**：1冊分の原稿を章ごとに書くと、リサーチも文体合わせも手作業で数週間溶ける

**やること**：企画書1枚から、リサーチ→本文執筆→ファクトチェック→文体統一まで1セッションで通し、新書1冊分の初稿（約88,000字）に到達させる。章単位で書くと数週間溶ける作業を一気通貫に。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
添付の企画書(kikaku.md)で新書1冊の初稿を書いてください。全7章×各10,000字以上。
リサーチ→執筆→Codexでファクトチェック→全章通読で文体統一、まで一気に。聞かずに最後まで進めてください。
```

**ひとこと**：「各章10,000字を下回らない」と数字で縛らないと薄い章が出る。並列執筆は章ごとに文体がブレるので、最後に全章通読で用語・敬体を1回統一する。
