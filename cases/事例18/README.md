# 事例18（🟠）：SEOの伸び悩みを、複数の検索データの照合で改善優先度に変える

**課題**：サイトのアクセスが伸びない理由を、感覚でしか語れずデータで掴めていない

**やること**：サイトのアクセスが伸びない理由を感覚でなくデータで把握したい → GSC・競合・Codexのデータを照合し、優先度付き改善リストに。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
自社サイトのSEOを診断して改善案を出して。
- GSC MCPで直近3ヶ月のクエリ/表示回数/クリック/順位/CTRを取得
- 分析:
  1. 表示は多いのにCTRが低いページ（タイトル改善余地）
  2. 順位11〜20位の「あと一歩で1ページ目」のクエリ
  3. 表示はあるが順位が低いキーワードの傾向
- 競合の上位記事をBraveで取得して比較
- Codex MCPにも同じデータを渡してセカンドオピニオン
- 各改善案に「期待効果（高中低）」と「具体的な打ち手」を付ける
出力: seo_shindan.md
```

**ひとこと**：最低3ヶ月分を渡す。順位11〜20位の「あと一歩」クエリに絞ると効率が高く、Codexのセカンドオピニオンで見落としが減る。
