# 事例22（🟠）：アンケート結果を、取得から離脱ファネル可視化まで1プロンプトで処理

**課題**：1,000人規模の生アンケートをExcelで読み切れず、貴重な声を放置してしまう

**やること**：1,000人規模の生の声をExcel手集計で読み切れず放置 → スコア分布・離脱ファネル・自由記述クラスタリングを1プロンプトでレポート化。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
survey.csv（大量回答）を分析してレポートにして。
1. 満足度スコアの分布（平均・中央値・分布グラフ）
2. 自由記述を意味でクラスタリングして上位5テーマ＋代表コメント
3. 申込→参加→完了の離脱率をファネルで可視化
4. 改善すべき点を3つ、根拠データ付きで
出力: survey_report.md + グラフ画像（分布・ファネル）
個人名・所属が含まれる記述はマスクして。日本語フォントはHiragino Sansで。
```

**ひとこと**：自由記述は「意味でクラスタリング」と指定。個人名・所属はマスク、日本語フォント崩れは「Hiragino Sans」で解決。
