# 事例31（🟠）：散在データから経営指標を並列収集し、根拠付き1枚に統合

**課題**：月初に売上見込みや未入金を出すのに、Slackやメールを横断して集めるのが大変

**やること**：月初に進行案件数・売上見込み・未入金・新規問い合わせをぱっと出したい → データ源ごとにサブエージェントを並列起動し、根拠付き1枚に統合。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
今期の経営状況を1枚にまとめてください。データ源はSlack主要ch直近・Gmailの請求/契約スレッド・契約書フォルダ・請求Sheet。指標は進行案件数/今期売上見込み/未入金/新規問い合わせ数/要対応の懸念事項。前期比も計算、金額は円表記固定、各項目に根拠リンクを添えて keiei_summary_202605.md に。
```

**ひとこと**：同じ案件が複数ツールに出たら1件に集約するルールを明示し、数値の横に根拠リンク（Slack URL・Gmailスレッド・契約書名）を必ず残させる。
