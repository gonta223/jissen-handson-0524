# 事例14（🔵）：Excel手集計の月別商品別ピボットを、データ汚れごとグラフ化

**課題**：月別×商品別の売上集計を毎月Excelで手作業、しかも日付揺れや空欄に毎回つまずく

**やること**：Excelで毎月手集計していた月別×商品別の売上ピボット＋グラフを、データ汚れごと数分で。日付揺れ統一・空欄補完してpandasでピボット、matplotlibで折れ線＋円グラフを出力します。

## 📋 コピペするプロンプト（Claude Code に貼る）

```text
sales.csv を読んで、月別×商品別の売上集計表とグラフを作ってください。
- 日付フォーマット揺れ(YYYY/M/D と YYYY-MM-DD 混在)を統一
- 金額空欄は「単価×数量」で補完、できなければ除外して件数を別途報告
- 月別×商品別の売上ピボット表(Markdown)
- 月ごとの売上推移を折れ線グラフ(PNG)で ./output/sales_chart.png に
- 商品別の構成比も円グラフで
- 日本語フォントはHiragino Sansを指定(豆腐対策)
- 最後に「伸びている商品・落ちている商品」を一言コメント
```

**ひとこと**：日本語フォント切れは「Hiragino Sansを使って」で一発解決。空欄は「単価×数量で補完、できなければ除外して件数報告」と処理方針を指定します。
