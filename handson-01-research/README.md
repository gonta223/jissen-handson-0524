# ハンズオン①：競合・市場リサーチ自動化エージェント

業界の競合5社を**一気に調べて → 比較表にして → 空白地帯を見つけて → HTMLダッシュボードにする**まで、
一気通貫でAIにやらせます。最後は「毎週自動で更新する仕組み」の設計まで。

題材は架空の「**法人向けAI議事録ツール市場**」。同梱の架空データだけで、**外部接続ゼロで全員完走できます**。

---

## ゴール像

```
5社のプロファイル(同梱)
   ↓ ①リサーチ（サブエージェント並列）
5社の要約
   ↓ ②分析
比較表 ＋ 空白地帯3点（output/report.md）
   ↓ ③HTML化
ダッシュボード（output/index.html）をブラウザで表示 ← ここが達成感のピーク
   ↓ ④自動実行の設計
毎週自動更新のひな型（automation/weekly_research.md）
```

## やり方（このフォルダで `claude` を起動して、下のプロンプトを順にコピペ）

> 起動：ターミナルでこのフォルダに入って `claude` と打つだけ。
> `cd ~/Desktop/cc-handson/jissen-handson-0524/handson-01-research`

### Step1　リサーチ（5社を並列で要約）
```
input/industry_list.md を読んで、input/companies/ の5社それぞれを
「価格帯・主要機能・ターゲット顧客・強み・弱み」の5観点で要約して。
5社を別々のサブエージェント（Haiku・読み取り専用）で並列に調べて、結果を1つにまとめて。
```
※ 重かったら「並列じゃなくて1社ずつでいいよ」と言えばOK（結果は同じ）。

### Step2　分析（比較表＋空白地帯）
```
5社を比較表にして、ポジショニングと「5社の誰も取れていない空白地帯」を3点提案して。
templates/report_template.md の型に沿って output/report.md に保存して。
input/market_notes.md の市場背景も踏まえてね。
```

### Step3　HTMLダッシュボード化（→ ブラウザで表示）
```
output/report.md の内容を templates/dashboard_template.html に流し込んで、
白背景・ティール基調の比較ダッシュボードを output/index.html として作って。
できたらブラウザで開いて。
```

### Step4　自動実行の設計（作るだけ・常駐化は家で）
```
このリサーチを毎週月曜の朝に自動更新する仕組みを設計して。
automation/weekly_research.md に沿って「スキル化の下書き・cron 1行・暴走を止める安全弁」を書いて。
実際に常駐させるのは今日はやらない前提で。
```

## ⏩ 倍速レーン（全部できた人向け・3つ）

1. **自分の業界でやる**：同梱データの代わりに、自分の業界の競合3社を **Web検索**で調べて同じレポートを作って（鍵不要）。
2. **スキルに昇格**：Step1〜3の手順を `research-competitors` スキルにまとめて、次回から1コマンドに。
3. **観点を足す**：比較表に「導入の手軽さ」「日本語精度」など独自の観点を1列追加して再生成。

## 使った機能（第1部の振り返り）

- **サブエージェント並列**（Step1）… 5社を同時に調べる。読み取り専用なので安全＆安い
- **スキル連鎖／スキル化**（倍速レーン）… 一連の手順を1コマンドに
- **自走・ルーチン**（Step4）… 毎週自動で回す設計（本番は持ち帰り）
