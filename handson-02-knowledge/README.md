# ハンズオン②：社内ナレッジAI社員

架空の会社「**株式会社みらいワークス**」の社内資料（規程・製品仕様・FAQ・営業ルール・議事録）を読み込ませて、
**「社内のことなら何でも答えるAI社員」** を作ります。

ポイントは **出典つきで答えること**。AIが資料を根拠に、ファイル名を添えて答えてくれる状態を体験します。
（本番では、この `knowledge/` を自社のGoogle Drive / Notion / Slack に置き換えるイメージ）

---

## ゴール像

```
社内資料 一式（同梱）
   ↓ ①中身を把握
どんな資料があるか分かる
   ↓ ②生メモ → 議事録化（資料は"作って増やせる"体験）
新しい議事録が knowledge/ に追加
   ↓ ③AI社員の人格を読む（CLAUDE.md＝出典必須ルール）
   ↓ ④質問する
出典つきで即答 ← 「社内専用AI」が動いた瞬間
```

## やり方（このフォルダで `claude` を起動して、下のプロンプトを順にコピペ）

> 起動：`cd ~/Desktop/cc-handson/jissen-handson-0524/handson-02-knowledge` → `claude`

### Step1　中身を把握
```
knowledge/ の中身を一覧して、どんな社内資料が入っているか3行で教えて。
```

### Step2　生メモ → 議事録化（資料はAIに作らせて増やせる）
```
knowledge/meetings/_raw_memo_20260424.txt の生メモを、
templates/minutes_template.md の型で議事録に整えて、
knowledge/meetings/20260424_営業会議.md に保存して。
確定したことと、まだ確定でないこと（要確認）は分けてね。
```

### Step3　AI社員の人格を確認
```
このフォルダの CLAUDE.md を読んで、あなたがどんなルールで答えるAI社員か3行で教えて。
```
※ CLAUDE.md には「必ず資料を根拠に・出典を添えて・無ければ"資料にありません"」と書いてあります。

### Step4　質問する（期待質問集.md からコピペ）
```
在宅勤務は週何日まで認められてる？根拠の資料も教えて。
```
ほかの質問は `期待質問集.md` に10問あります。1つずつ試してみてください。
「資料にないこと」（例：社員の平均年収）も聞いて、ちゃんと「資料にありません」と返るか確認しましょう。

### Step5　発展（できた人向け）
```
「資料を探す係」と「回答をまとめる係」にサブエージェントを分けて、
期待質問集.md の10問に一気に答えて。各回答に出典を付けて。
```

---

## 🆘 最悪ここまでライン

**Step4 で、1問でも「出典つきの正しい回答」が返ってくれば成立です。**
詰まったら `../completed/handson-02/` に完成形の議事録・回答サンプルがあります。

## ⏩ 倍速レーン（全部できた人向け・3つ）

1. **自社版にする**：`knowledge/` の中身を、自分の会社の資料（規程・FAQ・議事録）に差し替えてみる。
2. **時系列でまとめる**：「先月の決定事項を、製品・営業ごとに時系列でまとめて」と聞く。
3. **本番接続を知る**：本番は `knowledge/` の代わりに Google Drive / Notion / Slack を **MCP / gog で接続**して、生きた社内データをそのままナレッジにできる（第2部 応用②・gogで解説）。

## 使った機能（第1部の振り返り）

- **CLAUDE.md 設計**（Step3）… AIに「就業規則」を渡して人格・参照ルールを定義
- **出典必須＝ハルシネーション対策**（Step4）… 資料にないことは「ない」と言わせる
- **サブエージェント分業**（Step5）… 探す係とまとめる係に分ける
- **MCP / gog**（倍速レーン）… 本番は社内データに直結（持ち帰り）
